# Data Structures & Algorithms

**Summary:** Argues for the importance of fundamentals — data structures, algorithms and design patterns — and how they repeatedly show up in real systems and optimizations.

They told me data structures and algorithms were useless at work. They were wrong.

You don't need data structures and algorithms to build simple solutions to common problems, many of those have already been abstracted away for convenience. But having a solid grasp of them gives you the knowledge, mindset and creativity to tackle more complex challenges. That intrinsic understanding is what will set you apart from someone simply using an LLM going forward.

Lesson: Invest in learning data structures, algorithms and design patterns.

Once you know them, you start seeing the same patterns across different codebases, frameworks and systems. It saves you time, helps you write cleaner code and makes it way easier to work with large teams and large codebases.

Finally, if you want a shot at companies like FAANG, strong fundamentals are not optional. They are the price of admission.
