# Abstraction

**Summary:** Notes on when and how to apply abstraction to reduce cognitive load, avoid leaking implementation details and keep code intuitive.

Abstraction is most effective when it meets a few key criteria:

- It reduces the overall cognitive load, rather than introducing additional intellectual burden.
- It is intuitive, making it easy to reason about and explain to fellow developers.
- It avoids leaking implementation details, ensuring that the abstraction does not introduce more overhead or complexity than the value it provides.
