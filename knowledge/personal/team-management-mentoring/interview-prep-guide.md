# Exponent Software Engineering Interview Prep

**Summary:** Practical guide covering levels, coding & system design topics, behavioral prep, common mistakes and key themes to practice.

## 1. Introduction & Leveling
- Goal: Success depends on deliberate practice across coding, system design and behavioral questions.
- Note: Companies vary in leveling systems; understand the expectations for the role.

## 2. Technical Coding Interviews
### Assessment Rubric
- Technical skill, problem-solving and culture-fit are evaluated simultaneously.

### Common Mistakes
- Skipping clarification or failing to check in with the interviewer.

### Topics
- String manipulation, arrays/algorithms, KMP, binary search, inflection point problems.

## 3. System Design Interviews
- Focus on clarifying requirements, articulating trade-offs and collaborative design.
- Core concepts: load balancing, consistency, URL shortener, distributed LRU caches, message queues.

## 4. Behavioral Interviews
- Use the STAR method; prepare examples for failure, conflict and leadership.
