# Optiver Readiness Study Plan

**Summary:** A 24-week structured roadmap to transition into C++ trading systems: phases covering C++ foundations, systems and performance, trading domain, integration and interview prep.

A structured 24-week roadmap designed to build the C++, systems and trading-domain expertise required for a Core Software Engineer role in automated trading systems.

## Overview

This study plan is designed to help an experienced software engineer transition into high-performance C++ and low-latency trading systems. It spans 24 weeks and includes reading, coding exercises, system-level learning and hands-on trading-related projects.
