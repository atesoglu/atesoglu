# Tracy — Tracing & Tools

**Summary:** Overview of tracing tools and when to use them.

- Zipkin — lightweight distributed tracing.
- Jaeger — end-to-end tracing with visualization and sampling.
- Lightstep — commercial, ML-assisted tracing.
- Appdash — tracing for Go apps.
- Datadog — integrated monitoring + tracing.

**When to use:** instrument services, capture spans for entities (flight booking) and visualize service interactions to find latency sources.
