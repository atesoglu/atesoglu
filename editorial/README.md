# Editorial

Drafts, notes, and published pieces for technical writing (Medium, blog posts, etc.).

## Structure

```
editorial/
├── drafts/     # Work in progress — incomplete, unpolished
└── published/  # Final pieces ready for publication
```

## Guidelines

- **drafts/**: Rough notes, outlines, partial articles. No quality bar.
- **published/**: Polished, complete pieces. Ready to copy-paste to Medium/blog.

## Workflow

1. Start a new piece in `drafts/` (e.g., `drafts/2025-01-15-loosely-coupled-monolith.md`)
2. Iterate, refine, get feedback
3. When ready, move to `published/` (or copy if you want to keep draft history)
4. Publish to Medium/blog from `published/`
